# @antha/entity-2d

A pre-built [Antha](https://www.npmjs.com/package/antha) mod for rendering and handling collision detection for 2D entities. This requires a mod that has setup PixiJS in a manner compatible with [@antha/graphics-2d](https://npmjs.com/package/@antha/graphics-2d)

Demo: https://electrovir.github.io/antha/demo/basic-entities

## Install

```sh
npm i @antha/entity-2d
```
