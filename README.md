# Antha mono-repo

The Antha game engine (for the web), where everything is a mod!

This is a mono-repo. Look in [`./packages/`](./packages/) to see where all the stuff is happening.

## Published packages

-   [`antha`](https://www.npmjs.com/package/antha): bundled engine with the default mods.
-   [`@antha/engine`](https://www.npmjs.com/package/@antha/engine): the core web game engine.
-   [`@antha/asset`](https://www.npmjs.com/package/@antha/asset): asset loading.
-   [`@antha/audio`](https://www.npmjs.com/package/@antha/audio): audio loading and playback.
-   [`@antha/entity-2d`](https://www.npmjs.com/package/@antha/entity-2d): 2D entities.
-   [`@antha/fps`](https://www.npmjs.com/package/@antha/fps): an on-screen frame-rate counter.
-   [`@antha/gamepad-type`](https://www.npmjs.com/package/@antha/gamepad-type): gamepad model and layout detection.
-   [`@antha/graphics-2d`](https://www.npmjs.com/package/@antha/graphics-2d): 2D canvas graphics.
-   [`@antha/input`](https://www.npmjs.com/package/@antha/input): keyboard and gamepad input.
-   [`@antha/multiplayer-core`](https://www.npmjs.com/package/@antha/multiplayer-core): shared multiplayer functionality.
-   [`@antha/multiplayer-p2p-authoritative-host`](https://www.npmjs.com/package/@antha/multiplayer-p2p-authoritative-host): authoritative-host P2P multiplayer.
-   [`@antha/multiplayer-p2p-lock-step`](https://www.npmjs.com/package/@antha/multiplayer-p2p-lock-step): lock-step P2P multiplayer.
-   [`@antha/multiplayer-server`](https://www.npmjs.com/package/@antha/multiplayer-server): multiplayer signaling server.
-   [`@antha/util`](https://www.npmjs.com/package/@antha/util): engine utilities.
-   [`@antha/web-test-runner-plugin-pixi`](https://www.npmjs.com/package/@antha/web-test-runner-plugin-pixi): PixiJS support for Web Test Runner.

-   Demos: https://electrovir.github.io/antha/demo
